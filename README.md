# 掌上待办

原生 macOS AppKit 应用，本机 Apple Silicon 版本。

## 使用

双击 `build/掌上待办.app`。应用常驻菜单栏，没有普通窗口。

- 鼠标靠近任意显示器左侧边缘，手掌展开。
- 在手掌空白处短按并松开后出现光标，使用 16pt 翩翩体手写字输入（行距 2pt）；输入区无底框。长文字自动换行，Shift＋回车手动换行，回车落笔；中文输入法选字时不会提前提交。
- 输入时 Escape 取消。落笔后不支持修改。输入中点击另一处空白会保存当前文字，并直接在新位置继续输入。
- 按住 Option（⌥）拖动未完成文字可移动整条文字，移动和揉墨均不显示选框；移动限制在手掌内，位置自动保存。
- 新建输入只在短按松开时触发；长按或拖动不会新建，来回拖动即使回到起点也不会误判为点击。
- 直接在文字上按住鼠标来回揉动，墨水随方向拖散。累计至少三次换向并擦动一定距离，待办记为完成。
- 手掌获得键盘焦点时按 ⌘Z，或使用菜单栏「撤销上次涂抹」，恢复上一次按下到松开的涂抹，包括墨迹、完成状态和累计揉墨进度。支持当前运行期间最近 30 次涂抹；输入期间 ⌘Z 仍用于撤销输入。移动某条文字后，该条文字原位置的涂抹撤销记录会清除。
- 完成后的墨迹保留；未完成文字和墨迹跨天、重启保留。
- 鼠标离开手掌浮层和左侧唤出区后立即收回（手指间透明空隙不会触发收回）；正在输入的内容自动落笔保存。按住鼠标移动文字或揉墨期间保持展开，松开后移出即收回。
- 菜单栏手掌图标可以重新伸出手或退出。

数据位于 `~/Library/Application Support/HandTodo/`，完全本地保存。

## 构建与验证

在此目录运行 `./build.sh`，需要 Xcode Command Line Tools。构建产物为 `build/掌上待办.app`，采用本机临时签名。

运行 `build/掌上待办.app/Contents/MacOS/HandTodo --self-test`，验证文字移动、边界限制、位置保存、重叠文字隔离、旧数据迁移、文字绘制、墨水位移、完成状态与墨迹恢复；测试使用独立临时目录，不影响真实待办。

这是第一版可运行原型。尚未提供登录启动、字体/尺寸设置、云同步和发布用开发者签名。揉墨采用局部像素拖动，手感仍可按实际试用调整。

## 插画来源

手掌插画由内置 imagegen 生成，位于 `Resources/hand.png`。生成要求：透明背景，手腕从左侧进入，掌心朝向用户，拇指朝上，四指向右自然伸展，暖肤色、深棕轮廓、淡紫阴影的二维动画插画，无文字与界面。

## 贴合手掌的起伏

`Resources/hand-height.png` 是与当前手掌一一对应的 640 × 427 灰度起伏图，白色高、黑色低。根据掌心、拇指根部和五指的形态人工设定隆起，并加入浅掌纹；这是插画的近似体积，不是实测三维扫描。可用 `swift Tools/GenerateHeightMap.swift Resources/hand-height.png` 重新生成。

文字、输入光标和墨迹通过同一套起伏变形显示；移动和揉墨将鼠标位置反向映射到原始文字坐标。原始笔迹仍独立保存，避免反复变形导致模糊。旧待办也会使用新的贴合显示。

## 沿手指书写

落笔位置会自动匹配手指的轴向：拇指沿斜向，其余手指沿各自的伸展方向，掌心保持自然横写。文字先按局部书写方向旋转，再叠加起伏图变形；输入预览、光标、点击和揉墨使用相同的坐标转换。Option 拖动到另一个区域时，文字自动适应新位置的方向。手指可写空间不足时限制继续输入，避免笔画写到皮肤外。

## 画笔与涂画管理

点击手腕中央的手写「涂鸦」入口，选择「黑色画笔 / 红色画笔 / 蓝色画笔」（菜单栏也保留相同操作），即可按住鼠标在手上自由画图；选择「待办模式」返回键盘记录、揉墨完成和 Option 移动文字。

涂画以独立笔画保存在 `drawing.json`，与待办的文字墨迹分开。待办操作不会改动涂画，涂画也不会产生或完成待办。画笔模式下 ⌘Z 撤销上一笔；菜单栏还提供独立的「撤销涂画」和「清空涂画」，清空涂画后也可撤销。本次运行保留最近 30 次涂画操作的撤销记录。涂画会随文字一起跨天保留。

## 手掌插画 v2

当前手掌素材由内置 imagegen 基于原应用手掌和确认的示意图重绘。保留原轮廓、手指位置与透明背景，使用暖肤色、紫褐色分层阴影和更明显的掌心、关节体积。旧素材保存在 `Resources/Archive/hand-v1.png`。起伏图与书写坐标沿用原布局，文字和涂画仍动态叠加。

生成要求：以旧手掌为编辑对象，以确认的示意图为画风参考；锁定 3:2 画布、轮廓、手腕和五指位置，以明暗与体块增强轻微透视和体积；保留真正透明背景；掌心为空白，不含待办、涂鸦、按钮或桌面。

## 手掌插画 v3（当前）

依据用户再次指定的最初桌面示意图直接提取、清理手掌，去掉桌面、文字与墨迹。保留参考中的纤细轮廓、自然手指张开角度、淡桃肤色、细线和克制的灰褐阴影，避免 v2 过重的紫色块面与鼓起的掌心。内置 imagegen 编辑生成，保留透明背景。v2 素材归档于 `Resources/Archive/hand-v2.png`。

起伏图和手指书写轴向已按新造型同步更新。生成要求：参考手掌直接抠出清理，不创造新造型；保留参考比例、透视、纹理和明暗，仅删除背景与笔迹；适配 3:2 透明画布。

## 可调整的手账图案

在手腕工具入口选择「添加图案」，可添加 5 款圆珠笔涂鸦。添加后自动进入「图案模式」，也可在菜单中再次切换到此模式编辑已有图案。

- 点击图案后拖动移动。
- 在图案上滚动鼠标或触控板，放大或缩小。
- 按住 Option（⌥）滚动旋转；触控板捏合和旋转手势也支持。
- 右键图案可放大、缩小、每次旋转 15° 或删除；选中后按 Delete 也可删除。
- 图案模式下 ⌘Z 撤销图案操作；一次完整拖动算一步。

图案在 `stickers.json` 独立保存，各自记录位置、比例和角度，跨天保留。图案操作不影响待办文字和自由涂画。图案笔迹沿起伏图贴合皮肤，缩放范围为初始尺寸的 25%–300%。

## 洗手

在手腕工具菜单选择「洗手 · 清除所有内容」，清除全部待办文字、完成记录、揉墨残留、自由涂画和添加的图案。清理的是所有独立内容层，而非仅隐藏画面；重新打开仍然干净，手掌插画与工具入口保留。

洗手前会在本机保存一份恢复副本。手上尚未添加新内容时，可按 ⌘Z 或选择「撤销洗手」整体恢复，重启后也可恢复。空白手掌再次洗手不会覆盖恢复副本。普通文字、画笔和图案撤销历史会在洗手时清除，防止旧内容意外逐项出现。
