# 掌上待办

原生 macOS AppKit 应用，本机 Apple Silicon 版本。

## 使用

双击 `build/掌上待办.app`。应用常驻菜单栏，没有普通窗口。

- 鼠标靠近任意显示器左侧边缘，手掌展开。
- 在手掌空白处短按并松开后出现光标，使用 14pt 翩翩体手写字输入（行距 2pt）；输入区无底框。长文字自动换行，Shift＋回车手动换行，回车落笔；中文输入法选字时不会提前提交。
- 输入时 Escape 取消。落笔后不支持修改。输入中点击另一处空白会保存当前文字，并直接在新位置继续输入。
- 按住 Option（⌥）拖动未完成文字可移动整条文字，移动和擦除均不显示选框；允许部分文字越过手掌边界，只要仍有笔迹留在手掌上即可移动，位置自动保存。
- 新建输入只在短按松开时触发；长按或拖动不会新建，来回拖动即使回到起点也不会误判为点击。
- 直接在文字上按住鼠标擦除，圆环显示 8pt 半径的擦除范围。沿连续轨迹清除笔迹，边缘平滑，不拖散墨水；接近擦净时清除细小残留并将待办记为完成。
- 手掌获得键盘焦点时按 ⌘Z，或使用菜单栏「撤销上次擦除」，恢复上一次按下到松开的擦除，包括完整笔迹与完成状态。支持当前运行期间最近 30 次擦除；输入期间 ⌘Z 仍用于撤销输入。移动某条文字后，该条文字原位置的擦除撤销记录会清除。
- 擦净后的待办保留完成状态；未完成文字和剩余笔迹跨天、重启保留。
- 鼠标离开手掌浮层和左侧唤出区后立即收回（手指间透明空隙不会触发收回）；正在输入的内容自动落笔保存。按住鼠标移动文字或擦除期间保持展开，松开后移出即收回。
- 菜单栏手掌图标可以重新伸出手或退出。

数据位于 `~/Library/Application Support/HandTodo/`，完全本地保存。

## 构建与验证

在此目录运行 `./build.sh`，需要 Xcode Command Line Tools。构建产物为 `build/掌上待办.app`，采用本机临时签名。

运行 `build/掌上待办.app/Contents/MacOS/HandTodo --self-test`，验证文字移动、边界限制、位置保存、重叠文字隔离、旧数据迁移、文字绘制、精确擦除与零残留、完成状态与墨迹恢复；测试使用独立临时目录，不影响真实待办。

这是第一版可运行原型。尚未提供登录启动、字体/尺寸设置、云同步和发布用开发者签名。擦除按连续线段局部清除像素；开始擦动时保存原始笔迹用于撤销，不再反复复制整张画布或进行像素拖散。

## 插画来源

手掌插画由内置 imagegen 生成，位于 `Resources/hand.png`。生成要求：透明背景，手腕从左侧进入，掌心朝向用户，拇指朝上，四指向右自然伸展，暖肤色、深棕轮廓、淡紫阴影的二维动画插画，无文字与界面。

## 贴合手掌的起伏

`Resources/hand-height.png` 是与当前手掌一一对应的 640 × 427 灰度起伏图，白色高、黑色低。根据掌心、拇指根部和五指的形态人工设定隆起，并加入浅掌纹；这是插画的近似体积，不是实测三维扫描。可用 `swift Tools/GenerateHeightMap.swift Resources/hand-height.png` 重新生成。

文字、输入光标和墨迹通过同一套起伏变形显示；移动和擦除将鼠标位置反向映射到原始文字坐标。原始笔迹仍独立保存，避免反复变形导致模糊。旧待办也会使用新的贴合显示。输入预览按所在屏幕的像素密度绘制文字、选区和光标，并将手指旋转与曲面变形合并为一次采样，减少 Retina 屏幕上细笔画发虚；跨屏显示时自动匹配分辨率。拖动文字时缓存未变化的文字层，仅重算当前文字的有效像素区域；保持高清分辨率，避免每次移动都重绘整张画布。新待办同时保存 2 倍像素密度的原始笔迹，提交后与输入时使用相同的高清变形流程，重启、移动、擦除及撤销也保留这份高清笔迹。旧待办继续读取原有墨迹。

## 沿手指书写

落笔位置会自动匹配手指的轴向：拇指沿斜向，其余手指沿各自的伸展方向，掌心保持自然横写。文字先按局部书写方向旋转，再叠加起伏图变形；输入预览、光标、点击和擦除使用相同的坐标转换。Option 拖动到另一个区域时，文字自动适应新位置的方向。

长文字按落笔处的可用宽度自动换行；后续行超出手掌时仍允许继续输入和中文选字，不再因边界拦截而留下拼音。超出手掌或绘图区的笔迹暂时隐藏，完整原始笔迹会独立保存；落笔后按住 Option 拖动可让隐藏部分重新显现，移回、重启、擦除和撤销都保留相应内容。拖动时至少保留一部分笔迹在手掌上，避免整条文字被移丢。

## 画笔与涂画管理

点击手腕中央的手写「涂鸦」入口，选择「黑色画笔 / 红色画笔 / 蓝色画笔」（菜单栏也保留相同操作），即可按住鼠标在手上自由画图；选择「待办模式」返回键盘记录、擦除完成和 Option 移动文字。

在手腕「涂鸦」菜单或菜单栏选择「涂鸦橡皮擦」，按住并拖动即可局部擦除自由笔画，圆环显示擦除范围。文字与插图不受影响；⌘Z 或「撤销涂画」可恢复整次擦除。擦除结果重启后保留，也可在擦过的位置继续画。

涂画以独立笔画保存在 `drawing.json`，与待办的文字墨迹分开。待办操作不会改动涂画，涂画也不会产生或完成待办。画笔模式下 ⌘Z 撤销上一笔；菜单栏还提供独立的「撤销涂画」和「清空涂画」，清空涂画后也可撤销。本次运行保留最近 30 次涂画操作的撤销记录。涂画会随文字一起跨天保留。笔画按 2 倍像素密度从原始路径绘制，并在高清画布上完成曲面变形；已有涂画重启后也会按新清晰度重绘。

## 手掌插画 v2

当前手掌素材由内置 imagegen 基于原应用手掌和确认的示意图重绘。保留原轮廓、手指位置与透明背景，使用暖肤色、紫褐色分层阴影和更明显的掌心、关节体积。旧素材保存在 `Resources/Archive/hand-v1.png`。起伏图与书写坐标沿用原布局，文字和涂画仍动态叠加。

生成要求：以旧手掌为编辑对象，以确认的示意图为画风参考；锁定 3:2 画布、轮廓、手腕和五指位置，以明暗与体块增强轻微透视和体积；保留真正透明背景；掌心为空白，不含待办、涂鸦、按钮或桌面。

## 手掌插画 v3（当前）

依据用户再次指定的最初桌面示意图直接提取、清理手掌，去掉桌面、文字与墨迹。保留参考中的纤细轮廓、自然手指张开角度、淡桃肤色、细线和克制的灰褐阴影，避免 v2 过重的紫色块面与鼓起的掌心。内置 imagegen 编辑生成，保留透明背景。v2 素材归档于 `Resources/Archive/hand-v2.png`。

起伏图和手指书写轴向已按新造型同步更新。生成要求：参考手掌直接抠出清理，不创造新造型；保留参考比例、透视、纹理和明暗，仅删除背景与笔迹；适配 3:2 透明画布。

## 可调整的手账图案

在手腕工具入口选择「添加图案」，可添加 5 款圆珠笔涂鸦。添加后自动进入「图案模式」，也可在菜单中再次切换到此模式编辑已有图案。

- 点击图案后拖动移动。
- 在图案上滚动鼠标或触控板，放大或缩小。
- 按住 Option（⌥）滚动旋转；触控板捏合和旋转手势也支持。
- 右键图案可放大、缩小、每次旋转 15° 或删除；选中后按 Delete 也可删除。
- 图案模式下 ⌘Z 撤销图案操作；一次完整拖动算一步。

图案在 `stickers.json` 独立保存，各自记录位置、比例和角度，跨天保留。图案操作不影响待办文字和自由涂画。图案从原尺寸素材绘制到 2 倍像素密度的画布，旋转、缩放和曲面变形全程保留高清分辨率；重启后仍从原素材重绘。图案笔迹沿起伏图贴合皮肤，缩放范围为初始尺寸的 25%–300%。

## 洗手

在手腕工具菜单选择「洗手 · 清除所有内容」，清除全部待办文字、完成记录、擦除残留、自由涂画和添加的图案。清理的是所有独立内容层，而非仅隐藏画面；重新打开仍然干净，手掌插画与工具入口保留。

洗手前会在本机保存一份恢复副本。手上尚未添加新内容时，可按 ⌘Z 或选择「撤销洗手」整体恢复，重启后也可恢复。空白手掌再次洗手不会覆盖恢复副本。普通文字、画笔和图案撤销历史会在洗手时清除，防止旧内容意外逐项出现。

## 分发给朋友

- **macOS**：运行 `Distribution/package-macos.sh`，输出 Apple 芯片与 Intel 通用 DMG（macOS 13+）。
- **Windows**：运行 `Distribution/package-windows.sh`，输出 Windows 10/11 x64 便携 ZIP，包含独立运行的 `HandTodo.exe` 和中文说明，不需要另装 .NET。

Windows 为原生 WPF/.NET 8 适配版，源代码在 `Windows/`；构建需要 .NET 8 SDK，macOS 可交叉编译。GitHub Actions 会在 Windows 上构建、运行原生启动与核心功能检查，并保留测试截图和独立程序产物。两个平台分别在本机存储内容，不自动同步。

当前为未签名的朋友试用版，未提供 Apple 公证和 Windows 代码签名；系统首次运行可能显示来源提示。安装包不包含开发机上的个人待办、涂画或恢复备份。分发产物位于 `Distribution/output/`，不提交到 Git。

## 统一打包工具

以后打包统一使用 `./package.sh`：默认双平台，也可 `./package.sh macos` 或 `./package.sh windows`。默认版本从 `VERSION` 读取；追加 `--version x.y.z` 可指定本次版本。`--check` 检查环境，`--dry-run` 查看计划。

每次任务在 `Distribution/output/<版本>/<时间>-<提交>/` 生成独立产物、验证记录、日志与 SHA256，失败不会覆盖旧包或更新 latest 指针。Windows 原生验证默认自动执行；未经验证不会标成通过。详细流程见 [Distribution/打包流程.md](Distribution/打包流程.md)。

项目附有 `.agents/skills/handtodo-package/SKILL.md` 与 `AGENTS.md`；本机也已安装 `handtodo-package` Skill，后续说“打包”即可按该流程选路执行。
